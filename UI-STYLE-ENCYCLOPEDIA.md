# THE UI/UX STYLE ENCYCLOPEDIA — 112 styles, systematically

The pack's **full visual-style reference**. `MOTION-UI-STYLE-LIBRARY.md` holds the
working library (motion styles, the quick menu, the Style Pass); **this file is the
wide menu** — every style, grouped into ten families, with its key visual language.

> **How to use it.** Pick a **style** here, then set the whole system below it
> (see *The layered model*). Never ship a style on its own — a style is one layer.

---

## The layered model (think in layers, not one word)

A design direction is not a style — it is a stack:

```
Visual Style -> Layout -> Components -> Interaction -> Motion -> Typography -> Colour
```

Worked example — a **premium AI product**:

| Layer | Choice |
|---|---|
| **Style** | Glassmorphism + Aurora + Minimalism |
| **Layout** | Bento |
| **Components** | Floating cards + command palette |
| **Interaction** | Conversational UI + contextual actions |
| **Motion** | Microinteractions + smooth transitions |
| **Typography** | Modern sans-serif |

That is far more specific than "make it glassmorphic." Use this stack in the
**Style Pass** (`MOTION-UI-STYLE-LIBRARY.md`).

## How it plugs into the Style Pass

In `MOTION-UI-STYLE-LIBRARY.md` (Part D), when you set the **UI style** slot:

1. Pick a **style** from this encyclopedia (or the quick menu in Part B0).
2. Pick a **combination** from the list above if a pairing fits.
3. Fill the **layers**: Layout → Components → Interaction → Motion → Typography → Colour.
4. Name the **failure mode** of the style you chose, and prove it with a style frame.
